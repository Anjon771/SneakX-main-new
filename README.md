# SneakX - Sneaker Shopping App 👟

SneakX is a modern and feature-rich Flutter application designed. It offers a seamless shopping experience with functionalities like product browsing, cart management, and wishlist tracking. Built with **Flutter**, SneakX ensures a smooth shopping experience.

---

## Features 🚀
- **Sneaker Catalog**: Browse and explore an extensive collection of sneakers.
- **Cart Management**: Add items to your cart and manage them effortlessly.
- **Wishlist**: Save your favorite sneakers for later.
- **Modern UI**: Clean, responsive design optimized for Android and iOS.
